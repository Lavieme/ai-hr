# 知衡 · 校招筛选工作台

这是 AI-HR 网页的简化版本。HR 主流程为“准备材料 → 复核候选人 → 交付名单”。岗位评价卡和经理反馈保留在次级入口，需要时再处理。纯前端运行，无构建步骤。

## 使用

将本目录的 `index.html`、`styles.css`、`app.js` 放到现有 `ai-hr` GitHub Pages 仓库根目录，替换旧版 `index.html` 后发布。请先在测试页面检查旧项目迁移；旧版项目在同一浏览器、同一站点域名下会显示在首页“旧版项目”区域，点击后生成副本。

- 项目、评价卡、简历、人工结论与反馈保存在浏览器 `localStorage`。清除浏览器数据会删除这些记录。不同设备不会同步。
- 规则草稿在浏览器本地生成。AI 草稿需要用户主动输入 DeepSeek API Key；点击后，仅当前 JD 被发往 DeepSeek API，Key 不保存在本产品中。
- 新建项目和筛选依据页支持直接导入 TXT、Markdown、DOCX、PDF 和 PNG/JPG/WebP 图片。图片与扫描版 PDF 通过浏览器内 OCR 识别，识别结果会放入可编辑的 JD 文本框，须由 HR 核对。OCR 组件和语言包从 CDN 加载，需要网络连接。PDF 最多 12 页，单文件最多 15 MB。
- 简历导入支持 TXT、JSON、DOCX、PDF、ZIP。DOCX、PDF、ZIP 使用 CDN 加载的前端解析组件；扫描版简历 PDF 仍可能需要手动修正。
- 候选人原文、证据、队列、推荐结果支持盲筛。需要编辑原始简历时须主动关闭盲筛。
- 推荐名单只包含 HR 人工选择“建议进入面试”的候选人。推荐时需确认至少一项相关证据，或填写具体依据；无需逐项点完全部标准。系统只提供可能相关的原文线索，不自动判定招聘结果。

## 验证

`node --check app.js` 可做语法检查。此工作区的 `work/check-v4.cjs`、`work/check-jd-import.cjs`、`work/check-flow.cjs` 覆盖 JD 导入、重复检测、盲筛、简化流程及标准修订。
